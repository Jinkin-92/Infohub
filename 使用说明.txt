InfoHub 使用说明
================

一、先看这是什么
----------------
InfoHub 是一个本地运行的订阅中心。
安装完成后，你会在浏览器里打开一个网页，地址通常是：
http://localhost:3000

你可以在里面：
1. 连接微信、微博、X、知乎等平台
2. 添加订阅源
3. 手动刷新订阅源
4. 在一个页面里查看聚合内容


二、运行前准备
--------------
建议环境：
1. Windows 10 或 Windows 11
2. 能正常联网
3. 电脑上最好已经安装 Chrome 或 Edge

说明：
1. 如果你的电脑没有可用浏览器运行环境，安装时会自动补齐，这一步可能会比较慢。
2. 第一次安装通常最慢，后续再次启动会快很多。
3. 浏览器运行环境主要用于部分平台的重新连接登录；日常刷新不一定会打开浏览器。


三、第一次安装
--------------
1. 解压压缩包到一个固定目录。
   例如：D:\InfoHub

2. 双击运行：
   install.bat

3. 安装窗口会显示中文步骤提示。
   常见步骤包括：
   - 检查 Node.js 运行时
   - 准备配置文件和数据目录
   - 检查浏览器运行环境
   - 安装前后端依赖
   - 构建前后端产物

4. 安装完成后，窗口不会自动关闭。
   你会看到“安装已完成”的提示。

5. 如果安装失败：
   - 不要直接关闭窗口
   - 截图最后的报错信息
   - 把截图发给开发者排查


四、启动应用
------------
1. 双击运行：
   start.bat

2. 启动窗口会显示中文步骤提示。
   常见步骤包括：
   - 检查 Node.js 运行时
   - 检查配置、浏览器和依赖
   - 清理旧进程和旧日志
   - 检查端口
   - 启动后端和前端服务
   - 等待服务就绪并自动打开网页

3. 启动成功后：
   - 浏览器会自动打开 InfoHub 页面
   - 如果没有自动打开，请手动访问：
     http://localhost:3000

4. 启动完成后，窗口不会自动关闭。
   你可以确认成功提示后，再手动关闭窗口。


五、停止应用
------------
需要关闭 InfoHub 时，双击：
stop.bat


六、平台连接步骤
----------------
1. 启动后，进入页面右上角或设置页。
2. 打开“设置”。
3. 找到“平台连接”或类似区域。
4. 按平台逐个操作：
   - 微信：点击重新连接或扫码登录
   - 微博：点击重新连接
   - X / 知乎 / 小红书：按页面提示连接

建议：
1. 每次连接成功后，回到设置页确认状态是否显示正常。
2. 如果平台提示 cookie 过期，直接重新连接即可。
3. 微博现在只有在“重新连接”时才会打开浏览器，日常手动刷新不会再弹出浏览器窗口。


七、添加订阅源
--------------
1. 打开主页
2. 点击“添加订阅源”
3. 粘贴对应平台的链接或输入目标信息
4. 保存

添加完成后，订阅源通常会出现在列表中。


八、手动刷新订阅源
------------------
1. 在主页找到对应订阅源
2. 点击刷新、采集或类似按钮
3. 等待结果返回

如果刷新成功，通常会看到：
1. 新内容数量
2. 最新采集时间
3. 列表内容更新


九、如果看不到内容
------------------
按这个顺序排查：
1. 先确认平台连接是否仍然有效
2. 再确认订阅源地址是否正确
3. 再手动刷新一次
4. 如果还是失败，查看启动窗口里是否有报错

常见情况：
1. 平台登录态过期
2. 目标页面暂时访问失败
3. 某个平台限制较严，需要重新连接
4. 如果微博测试或刷新失败，优先重新连接微博，而不是重复重启应用。


十、更新应用
------------
如果拿到新版文件：
1. 先关闭 InfoHub
2. 用新版文件覆盖旧目录
3. 双击运行：
   update.bat
4. 更新完成后，再运行：
   start.bat


十一、这份安装包里包含了什么
----------------------------
为了兼顾安装速度和压缩包体积，当前策略是：

通常会内置：
1. 前端构建产物
2. 后端构建产物
3. 启动、安装、更新脚本
4. 说明文档
5. 在体积允许时，内置便携 Node.js 运行时

通常不会内置：
1. Chrome / Edge 浏览器运行时
2. backend node_modules
3. frontend node_modules

原因：
1. 浏览器运行时和 node_modules 体积太大，变化也更频繁
2. 为了把分发包尽量控制在 50MB 以内，不适合整体打进去
3. 微博日常采集已经改成直接使用已保存的登录 cookie，通过 HTTP 获取数据，所以不需要每次采集都依赖浏览器窗口


十二、遇到问题时请提供这些信息
------------------------------
如果需要反馈问题，请尽量一起提供：
1. 你运行的是 install.bat 还是 start.bat
2. 最后一屏报错截图
3. 是否成功自动打开了 http://localhost:3000
4. 是哪一个平台连接失败
5. 是哪一个订阅源刷新失败


十三、最短使用流程
------------------
1. 双击 install.bat
2. 等待安装完成
3. 双击 start.bat
4. 浏览器打开后，进入设置连接平台
5. 回到主页添加订阅源
6. 手动刷新订阅源
7. 查看采集结果
